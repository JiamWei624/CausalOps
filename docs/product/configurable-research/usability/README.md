# P3 第三阶段试用材料

本目录用于检验用户能否用当前受限功能完成研究，不增加统计能力。原准备基线为开发产品 `9dc0954`；本目录为0.20.0b1保留的试用材料，未附参与者记录，也没有真人完成率。

- [试用协议与当前用户旅程](PROTOCOL.md)：范围、招募、隐私、模式对照和验收。
- [参与者任务说明](PARTICIPANT.md)：只提供研究目标、数据背景及完成标准，不教授按钮路径。
- [知情同意模板](CONSENT.md)：默认不录屏、不录音、不外发，不代表任何人已经同意。
- [主持与观察手册](FACILITATOR.md)：环境、分级帮助、理解复述及结果复核。
- [行为指标和记录格式](RECORDING.md)：区分人、脚本、产品里程碑与真实操作。
- [本期交付与模拟结果](../PUBLIC_SUMMARY.md)：实际执行结果和未验证事项。

试用材料和空记录由 `scripts/usability_study.py prepare` 生成到仓库之外。它不招募参与者、不批准研究、不执行统计，也不把开发者预览算为独立真人测试。
