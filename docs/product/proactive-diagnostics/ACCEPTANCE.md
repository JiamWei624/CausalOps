# 三个代表性验收场景 · 待开发执行

这是未来工程验收设计；本轮只检查文档、Schema与原型，不执行以下研究、不产生新分数，不重跑V2.3。规则与产品实现冻结后再验收，失败/超时/解释不足必须保留。

## 共同证据与判据

每次记录：代码/规则/合同版本，输入/Plan/Run引用与hash，Finding原文与状态、严重度依据、报告可见文本与截图、Action/Decision事件、原审批与Run数量前后。模型关闭/开启分开计，开启必须为真实授权接口，不能用模拟响应冒充。

结构合法、统计来源正确、解释完整、操作安全分别核对。原工具执行成功不能自动判定诊断或答案完整；模型建议被拒绝也不能记为模型正确。

## A：证据完整且固定目标可回答

**起点**：隔离环境通过原界面和一次整体审批完成真实Hillstrom固定五步，产生独立S02/S04与原S05。使用公开数据，不硬编码示例数字作为新Run。

**操作**：完成事件触发只读评估；用户打开三层报告、查看任一依据、刷新和重新选择原报告。默认无模型。

**期望**：
1. PD-01/03—10/14以真实产物满足；PD-02明确为来源记录与人工声明核对，不写成随机化程序证明。
2. 无基线协变量则PD-11为尚未检查；PD-12列明未验证假设，不能整体全绿、不能为数量编造新风险。
3. 第一层数值/单位/区间/样本/窗口/Run与原运行一致；原估计器、批准、两个Run和原S05保持hash。
4. 结果适用范围及未知条件完整。当前目标没有必须追加分析时，建议可为0；不可为了显著性建议反复分析。
5. 新增诊断模块改变全包指纹后，旧完成任务仍可按原版本核验只读结果，显示不能沿用旧批准执行；旧未完成任务不得自动迁移/重签。
6. 刷新不新建统计，重复评估返回同上下文有效快照；后续规则版本变化产生新Assessment，旧版保留。

**完整**：以上均满足，依据可找到。**部分**：安全和数值正确，但解释/可达性遗漏。**失败**：编造检查、未知显示通过、错单位/错Run、擅自追加统计或改批准。若真实输入已损坏而安全停止，另记正确阻断，不冒充正常完成。

## B：来源与随机化依据不足

**起点**：已有原生单表任务，字段为Hillstrom相关两组访问数据，但DataContract的assignment/设计来源未确认。只读预诊断，无Plan/AB Run。不能从固定create_hillstrom绕过来源核验进入此状态；也不能先谎称随机化生成AB再反过来测诊断。

**操作**：请求核查“该证据是否支持随机实验解释”，查看来源缺项，选择“采纳补充来源”或“暂不处理”。

**期望**：
1. PD-02 unknown+major，明确缺公开设计依据/可核对人工声明；不能从两组、平衡或组名推断随机化。
2. 对没有产物的统计检查为尚未检查；plan_ref=null和空run_refs按合同表达，页面不显示示例A的效应和区间。
3. 给出具体补充路径；只登记证据请求/需求草案。暂缓不解除限制，补充说明也不签发批准。
4. 如补充改变正式合同，使用既有版本接口；新统计必须另行生成受支持方案并审核。原固定入口和旧审批不放宽。

**完整/正确澄清**：具体、同源、无统计副作用。**正确阻断**：用户进一步要求未授权因果执行，系统拒绝并说明原因。**部分**：安全但缺项泛化或建议不明确。**失败**：编造来源、自动登记randomized、生成无请求待审计划或执行/展示AB。

## C：结果/口径或引用冲突

**主起点**：两个真实、合法且独立的Hillstrom原生任务A/B，各自审批和Run完整；数值可以相同。只在隔离诊断请求中错误引用B的Run为A整合，原记录不修改。

**操作**：打开A的诊断报告，查看阻断依据、尝试暂不处理/采纳核对建议，切换回各自合法历史报告并刷新。

**期望**：
1. PD-01/07识别任务/Plan/批准/引用不匹配，issue+critical；不能因为数值一样而通过。
2. 不显示错误联合结果，不引用另一会话的数据或暴露其研究明细；只展示本任务验证失败观察。
3. 采纳仅进入来源核对；暂缓仍保留限制；重新选择合法引用后形成新Assessment，旧诊断保留。
4. 不产生新统计、批准、撤销、恢复或历史覆盖。

**两个有限反例**：
- 用户明确改问7天，而真实指标只有两周0/1。显示口径不匹配/缺少对应数据，不能虚构一个七天Run，也不把7天文字覆盖DataContract的两周语义。
- 在隔离副本破坏S02工件hash。原门禁先阻断；诊断只引用验证失败观察，不从受损正文补数字，S04不得因诊断而执行。

**完整/正确阻断**：能说明受影响结论并保护来源/历史。**部分**：安全停止但说明不完整。**失败（发布阻断）**：错误整合、跨任务事实泄漏、伪造Run、用旧窗口冒充新窗口、未经批准执行或修改历史。
