# 自动化方向需求概要
**V1.0 候选｜产品规划，尚未实施｜2026-11-05**

本概要落实产品负责人本轮认可的自动化方向，不是完整开发 PRD，也不构成开发授权、排期或已实现功能证明。产品现状与实测限制仍以 [Beta 总体 PRD](02_Beta总体PRD.md)和[评测账本](04_产品指标体系与版本路线图.md)为准。

## 1. 三阶段定位与能力边界
| 阶段 | 定位 | 范围与价值方向 | 状态 |
|---|---|---|---|
| 当前 Beta | 可审核、可追溯的 AI 数据科学 Agent | 单表分析、结构化方案、人工审核、统计执行与结果追溯；业务分析人员为主，科研人员为专业扩展用户 | 已有实现及限定验证；单用户本地 Beta，解释与交付仍有限 |
| 下一代 | 受控自动化的数据科学 Agent | 有界多步骤自主研究规划、工具协调、基于证据的主动诊断、结果整合与必要人工接管 | 负责人已认可方向；具体功能待专项 PRD 确认，尚未排期开发 |
| 长期 | 自动化数据分析与研究工作台 | 逐步扩展多表、外部数据源、周期性分析、异常触发与持续工作流 | 长期愿景；没有已实现或生产级验证声明 |

当前已有有限 Plan 步骤、检索、门禁及后台任务，不等于已经具有通用步骤依赖、主动研究闭环、预算控制或周期性工作流。现有能力是未来可复用的基础，不是下一代能力的验收证据。

## 2. 已认可的需求优先级
| 优先级 | 方向 | 关系 |
|---|---|---|
| 持续 P0 | 研究正确性、证据约束、审批与执行安全 | 所有版本持续遵守的底线 |
| P1 | 有界多步骤自主规划 | 下一代首要方向 |
| P1 后续 | 基于证据的主动诊断 | 建立在有界规划与步骤证据之上 |
| P2 | 多表数据与指标管理 | 单独处理连接、粒度与口径 |
| P2 | RAG 专项评测与必要优化 | 先专项测量，再决定必要优化 |
| P3 | 定时任务、外部工作流和多人协作 | 根据后续场景需求设计 |

**P0 不要求所有开放研究问题全部通过后才允许新功能。**对于计划支持的任务，必须明确可用条件、失败停止、审批和证据约束；不支持的问题可以澄清或拒绝。真实的越权执行、证据混用或无依据结论风险仍须按影响处理，不能通过降低安全标准换取自动化范围。以上优先级不是时间表或人员投入承诺。

## 3. 第一版建议边界
| 维度 | 建议纳入 | 明确排除 |
|---|---|---|
| 数据 | 单表，来源和基本字段口径可确认 | 多表连接、自动抓取外部数据 |
| 任务 | 有明确目标，可转成有限研究步骤 | 无目标探索、无限自主迭代 |
| 工具 | 现有注册统计方法，在其数据和设计条件内使用 | 新估计器、任意生成代码执行 |
| 规划 | 有步骤依赖、输入输出和完成条件的有界计划 | 自行扩展研究范围直至获得显著结果 |
| 审核 | 关键研究方案人工审核；范围变化须重核许可 | 未经授权执行、模型代批、自动勾选 |
| 推进 | 已获许可且条件满足的步骤，保留运行证据后再推进 | 遇到事实冲突、无效批准时静默继续 |
| 整合 | 按步骤与目标汇总结果，保留来源和限制 | 跨运行混合单位、指标或窗口 |
| 停止与接管 | 步骤、费用、失败边界；停止原因、已完成内容和待确认事项可见 | 无上限重试、无成本约束、不说明原因的停止 |

这是建议范围，需在正式专项 PRD 中定稿。具体步数、费用上限、失败重试数和审批颗粒度本轮不编造。

## 4. 用户价值假设与继承规则
希望减少明确任务中手工串联多个合法分析步骤的负担，同时让用户能理解系统当前依据、已完成步骤、待审内容和停止原因。**尚无真人提效或自主推进率数据**，不得以规划替代收益验证。

从 N06 继承四种状态的分离：
- 预览/观察：查看数据，不改变正式目标。
- 正式计划：明确步骤、指标、窗口与版本。
- 批准：授予指定范围内的执行权限，不因模型改计划而自动扩展。
- 执行证据：记录真实发生的步骤与结果，不把“计划执行”写成“已经完成”。

即使自动推进已批准步骤，也必须区分候选、批准、运行中、已完成、失败停止与等待人工处理。具体 UI 和状态协议属于未来专项 PRD，本轮不设计新页面或修改现有状态机。

## 5. 验收方向（尚未实测）
- 计划有效性与端到端完成分别测量，模型建议正确和门禁纠错分别计分。
- 每个执行步骤能回到获批版本、工具配置、输入及输出证据。
- 人工审核属于必要治理，不应为提升“自主率”而绕过。
- 超预算、条件冲突、失败不能恢复时正确停止；有必要时提出具体接管事项。
- 数值交付与研究解释都要覆盖用户目标，缺少证据时说明。
- 失败、超时、提前停止、错误继续及未执行位置均保留。

指标定义见[自动化指标](04_产品指标体系与版本路线图.md#automation-metrics)。本概要不设尚无依据的验收百分比。
