## 已明确的定位与优先级
- 当前 Beta：**可审核、可追溯的 AI 数据科学 Agent**；单用户本地、单表、方案审核、统计执行与追溯。
- 下一代：**受控自动化的数据科学 Agent**；有界规划、工具协调、主动诊断、结果整合与人工接管。
- 长期：**自动化数据分析与研究工作台**；多表、外部数据源、周期性分析、异常触发和持续工作流。

业务分析人员为主用户，科研人员为专业扩展用户；营销实验为首要演示。具体痛点和收益仍待真人验证。

统一优先级：持续 P0 研究正确性、证据约束、审批与执行安全；P1 有界多步骤自主规划；P1 后续基于证据的主动诊断；P2 多表数据与指标管理；P2 RAG 专项评测与必要优化；P3 定时任务、外部工作流和多人协作。P0 不要求所有开放问题全部通过才发展新功能。方向已认可，具体范围、排期和开发仍未批准。
