# CausalOps 项目技术与成果总结

## 项目定位与个人贡献

CausalOps 面向需要核对分析依据的科研人员和业务分析人员。常见场景是收到一份单表数据，知道希望回答的问题，但仍需明确分母、观察窗口、分组和比较方法。交付物包括可审核的方案、统计报告和能定位到具体运行的解释。

项目由本人独立发起和规划，具体工程实现大量使用 Codex 辅助开发。面试中可说明本人提出了哪些问题、如何确定产品边界、为什么采用某项验收标准，以及如何根据失败证据决定优先级。工程成果按项目记录陈述；涉及本人亲自完成的编程或人工评审工作，应以实际参与情况为准。

## 从用户问题到研究记录

营销实验给出了一个可复核的起点。首页展示公开汇总，导入原始数据后才创建用户自己的研究。系统固定分析单位、两组样本和两周访问指标，生成待审计划。使用者确认口径，执行器计算两组比例及差值，报告保留来源。用户再问“提高了多少”时，答案应同时区分百分点与相对增长。若改问次年净利润，还需成本、收入和相应时段；两周访问数据本身无法回答。

Streamlit 用于本机交互。ResearchService 将问题、方案、数据字典、审批和结果组织在同一研究会话内。LangGraph 记录任务进入哪个步骤，并在审批处中断。这样即使计划已生成，模型也没有执行新计算的权限。方法研究子图使用 LangChain 检索适配，从有来源的方法资料查适用条件和诊断项；寻找研究设计依据与查找某次运行的结果使用不同的数据来源。模型服务可选，负责解释和生成候选建议。单位换算、证据匹配及可计算性检查在已有证据支持的范围内由程序处理。

统计执行采用白名单分派。已注册 17 个方法入口，覆盖探索、实验、观察性比较和进阶研究设计。SQLite 保存本地任务与审批状态，表格和运行产物留在单用户工作区。结果解释关联运行编号、指标、窗口和事实引用。更换窗口或指标要求重新核查和批准；历史报告可以再次打开。具体输入、输出与函数入口见[架构说明](../current/ARCHITECTURE.md)。

## 怎样验证产品

- **程序回归**核对确定性边界。阶段冻结时 755 项通过、0 跳过。它说明本次环境下已有断言成立；不同方法仍有各自的验证深度。
- **固定研究任务**用于捕捉回退。V1 基线 8/10；处理后协变量和重复实体解释修复后为 10/10，最终产品的历史重放仍为 10/10。
- **重复挑战与真实模型**分别计分。本地规则、模型研究建议、确定性门禁和最终回答可以有不同表现。V1.2 原挑战集中，本地 15/45、DeepSeek 34/45；这组结果对应当时的题目和版本。
- **浏览器模拟**覆盖用户看见的内容。V2 Pilot 后台证据通过 16/18，而最终回答完整仅 2/18。V2.1 复测中分别为 18/18、12/18。这一落差促使项目把“结果算对”和“用户收到正确回答”分开验收。最终产品 B05/B06 独立长流程各通过 8/8 项检查。
- **陌生任务首次测试**暴露泛化限制。最终产品十题中 3 项完整、2 项部分、5 项失败，包含两次只读请求错误创建待审候选。十题均保留历史运行，未观察到未经批准执行。独立真人完成率与实际提效暂待测量。

以上数字的版本、分母和出处见[阶段验收](验收与整合.md)。

## 可用于面试的两个案例

**单位正确仍可能答错问题。** 用户想知道每百公里耗油量，而现有报告只记录油量和运行小时。早期版本会建议补充时长。修复将分母的业务对象、单位及窗口纳入确定性核对，要求同期实际行驶里程。记录也可能需要先按线路聚合；总油量除以总里程和各线路油耗率等权回答的是两个问题。最终已知十二题回归 12/12，但陌生问题仍可能被送进待审，这一限制已列入风险登记。

**用业务数字检验研究助理的交付。** 实际公开实验中，从 64,000 名客户预先选定 42,613 名进入两臂比较，男装邮件组与未发邮件组两周访问率分别为 18.28% 与 10.62%，绝对差 7.66 个百分点，95% 区间 7.00 至 8.32 个百分点。这个数值是公开实验的统计发现，不是 CausalOps 带来的业绩提升。产品的可验证贡献是让使用者从原始文件走到可复算的结果，并在同一运行上追问、查证和导出。[实际教程](../current/PUBLIC_TUTORIAL.md)

## 按岗位选择讲述重点

|方向|可使用的项目表述|适合深入讲解的证据|
|---|---|---|
|AI 产品经理|独立规划面向研究人员和业务分析人员的单表分析工作台，设计从问题确认、计划审核、计算到证据追问的操作流程；将后台正确性、页面可见性、最终答复完整性分层验收。|用 V2 的 16/18 对 2/18 解释为什么改变产品验收标准，再展示本轮实拍教程。|
|AI 应用开发|借助 Codex 完成研究工作流实现与迭代，结合 LangGraph、方法检索、确定性统计工具和版本化审批，支持持久会话、历史运行切换和可引用的结果解释。|沿代码追踪一次 ResearchService.review、一次运行及后续引用，说明哪些权限属于用户。|
|AI 数据科学|将指标口径、处理时点和分析单位纳入研究设计检查，用公开实验复算两周访问率差；分别检验分母匹配、层级汇总与结果解释。|演示 7.66 个百分点和 72.14% 相对变化的换算；说明 PSM 小样本模拟为何不足以宣称区间覆盖可靠。|

本阶段可展示单用户工作台和经核实的公开案例。面向不熟悉的数据、开放式研究目的、复杂跨表指标或企业多人协作时，仍需要人工确认口径与后续产品验证。下一阶段优先测量操作成本与恢复，再考虑扩大模拟任务规模。
