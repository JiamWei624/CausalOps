# 已知限制与公开范围

## 当前已实现
单表Beta、17个注册方法、版本化合同与方案、审核、统计证据；新增固定Hillstrom五步、两次Run、上游核验、持久预算、暂停/取消/核查恢复与工作台。

## 需要说明的限制
- 只开放固定两组访问率，不支持通用自然语言自主多步规划；无多表、长期研究记忆或复杂主动诊断。
- 研究解释、方法条件和最终答复仍有历史失败。V2.3开发集本地9/30、模型15/30；保留实际执行各13题确认正确0/13、另7题未执行。
- 单用户本地架构，无生产级并发、租户隔离或真人效率证据。固定浏览器结果不代表开放探索表现。
- 暂停在步骤边界生效；SQLite与文件之间不承诺物理恰好一次。不确定Run保留并核查，不能强制恢复。
- 来源确认与研究假设不同于程序可证条件。没有全面验证无干扰及长期外推。各方法统计核验深度不同，PSM等限制不隐藏。
- 费用依赖有版本的价格和真实回执，未知用量不能当作零；本固定计划不调用模型。

## 材料分发
公开：源码、必要资源、葡萄酒公开样本、确定性合成开发数据、通用工程测试、去敏汇总、实际公开场景截图及使用说明。
本地：论文与私人研究文件、微博原始/派生数据、实际工作区及数据库、凭据、原始评测会话、隐藏题与参考答案、完整本地开发历史、带本机信息的原始记录。

公开Beta继承原远程历史，其中曾出现私有数据目录名称和测试假凭据。新快照不能消除已经公开的历史字面量。本轮不重写历史或推送标签。该既有风险与新增内容扫描分别记录。
