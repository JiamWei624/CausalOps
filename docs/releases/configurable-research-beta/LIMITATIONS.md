# 0.20.0b1 能力限制

1. 本地单用户Beta，未做生产级多人验证。**目前尚无真人独立使用的正式验收数据。**脚本、工程、模型技术调用不是用户效率证明。
2. 可配置入口仅单表、双组、二元结果、确认的独立观察单位；不支持重复测量、任意筛选、连续值自动二分、通用多表或PSM/DID自主规划。
3. 窗口声明整张表，不自动按日期切片；新窗口需真实新范围数据。程序不能证明使用者登记的时间语义。
4. 来源、随机化和独立性由使用者核对；程序检查声明及证据链，不证明实验真实随机。存在两组或均衡不是证据。
5. 未知分配机制只允许描述路径，没有A/B Run、因果效应或区间。描述完成不等于效果研究完整。
6. 原A/B区间为1.96正态近似，小样本和稀少事件可能不足；没有新增精确检验、功效、无干扰或全部识别条件检查。
7. 六项诊断及其五状态不代表14项全通过；八项未实现，无总体可信度分数，模型解释关闭。
8. 模型仅提出两个支持路径的候选，不能改事实、扩方法、自动批准或执行；原始行默认不发送，但合同文字也可能敏感，须逐次预览授权。
9. 历史真实模型验收仅2次/6036令牌，费用未核实。本轮不为确定性任务强制调用模型；无广泛模型规划可靠率或成本收益结论。
10. 决定和需求草案没有执行权，历史决定不是事实证明；仅同任务确定性关联，不理解任意自由文字，不跨任务模糊迁移。
11. 开放式方法建议、统计解释和复杂只读回答仍有历史准确性限制；不能把固定任务通过率当作通用正确率。高风险研究及业务决策需专业复核。
