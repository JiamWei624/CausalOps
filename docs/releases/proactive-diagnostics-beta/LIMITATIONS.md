# 已实现范围、限制与公开材料

已实现：本地单用户单表研究、17项注册工具、版本化方案与人工审核、运行证据；固定Hillstrom五步、整体批准／逐步授权、预算与核查恢复；显式预诊断和运行后证据检查、六项规则和五态、同源三层报告、最多三条有依据建议、无执行权限需求草案和历史版本。

## 当前限制

- 不是后台持续监控，模型解释关闭，诊断流程不调用DeepSeek。
- 六项满足不代表所有研究假设通过；八项规则未实现，不计算总可信度分数。
- 执行后诊断限于固定Hillstrom证据结构；其他登记研究只使用已有预诊断范围。
- 随机化来源一致是来源与人工声明核验，不证明真实随机化过程；无依据时为未知。
- 不支持任意目标自主规划、通用多表、完整主动诊断、完整决策记忆或生产级多人服务。
- 草案无执行权限，不能直接批准、转入执行或自动增加方法。
- 开放式研究条件、指标与解释仍有历史失败。Eval V2.3开发集为本地9/30、DeepSeek15/30；保留集每模式执行13题，已确认正确0/13，另7题未执行。不能合为通用50题准确率。
- 没有真人完成率、效率或收益数据，高风险决策须专业复核。
- 加载核验会重绘页面，阅读位置可能变化；固定间隔采样不能穷尽所有瞬间。
