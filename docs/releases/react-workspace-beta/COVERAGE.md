# 0.21.0b1能力覆盖与兼容入口

默认入口为React；“完整工作台与专业工具”打开同一启动器管理、同一CAUSALOPS_HOME的Streamlit。两端使用原Python领域服务，不复制统计事实数据库。

|功能|React|Streamlit / 原服务|限制|
|---|---|---|---|
|会话与研究身份|完整受限支持：独立会话、绑定、搜索、持久化与恢复|原任务及历史保留|会话标题不作为任务ID，每轮引用冻结|
|CSV/Parquet与合同|支持正式字段、组别、二元编码、单位、窗口与来源确认|原DataContract|单表双组二元，20MB上传；不自动日期切片或填补|
|确定性候选|描述性4步或符合条件的5步研究；显式采纳|原CandidatePlanning|采纳不等于批准|
|模型候选与连接|未迁移；React消息当前本地确定性模式|Streamlit保留授权、预算与受约束模型候选|不是通用自主规划；本候选验收模型调用0|
|正式审批与执行|默认未勾选；批准后独立开始|原Approval、ToolGateway、BoundedCoordinator|每步核对原批准范围，聊天不授权|
|预算、暂停、取消与恢复|读取真实持久状态和预算，使用原控制服务|原BudgetLedger、后台作业与调和|取消终态，不承诺任意故障下物理恰好一次|
|统计报告与追溯|真实Run、完整报告、来源与导出|同一ReportManifest及原精度|百分比/百分点区分，无证据不补数|
|六项诊断与三层报告|显式预诊断/执行后诊断及历史|原六规则与不可变快照|其余八项未实现，无总体可信度分数|
|研究决定与修订|接受、暂缓、拒绝、自主备注、追加历史与确定性提醒|原ResearchDecision|无执行权限，不跨任务语义关联|
|研究需求草案|创建未迁移|Streamlit可显式保存无权限草案|不是正式研究计划或批准|
|专业方法|未提供17项完整配置器|Streamlit专业分析与17项注册方法|注册数量不代表自动规划全部方法|
|原单次研究及管理|读取适用产物，完整操作未全面迁移|原Streamlit入口保留|从兼容入口进入，不删除功能|
|公网多用户|不支持|不支持|仅本地回环、单用户受限Beta|

当前没有真人独立使用的正式验收数据。工程与脚本测试不是用户增长、提效或通用研究可靠性证明。
