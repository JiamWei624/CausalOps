# 0.21.0b1 候选变更说明

相对已公开0.20.0b1，新增真实React受限研究工作台：会话、附件、合同、确定性候选、显式采纳、正式审核、独立开始、真实状态与预算、暂停/取消/核查恢复、报告、显式诊断、决定与历史。正式统计仍由原Python服务计算。

本次发布准备新增统一Windows启动器、同源健康与身份检查、包内生产资源完整性核对、Windows子进程生命周期管理、锁定安装依赖和完整React教程。普通安装使用者不需要Node.js，开发构建仍按package-lock.json复现。

React成为默认入口；Streamlit没有删除或停用，17项专业方法配置、需求草案、原单次研究及受约束模型入口仍从兼容工作台进入。没有新增估计器、诊断规则、模型能力或研究执行权限。旧批准因版本/源码变化失效时仍按原门禁处理，历史结果不被覆盖。

本轮是本地候选，尚未授权公开推送。模型调用0，真人独立使用验证仍未执行；历史工程回归与本轮发布验证分开列明。
