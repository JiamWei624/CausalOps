# 0.21.0b1 安全、历史风险与能力限制

## 当前运行边界

仅本地回环地址、本地单用户。启动器校验两个端口、版本、匿名工作区摘要和服务实例；不连接或关闭未知端口。Windows监督进程管理自己的两个服务进程组，退出后保留数据库、Run与检查点；恢复继续走原服务核查。

React接口保持Host/Origin、浏览器Cookie、CSRF、绑定/版本/哈希和幂等校验。健康入口只读返回版本、实例和匿名工作区指纹，不提供CSRF、研究数据或执行权限。前端不获得密钥，不直接写SQLite、不运行估计器。默认不启用外部模型与追踪。

聊天文字、候选采纳、诊断、建议、需求草案和研究决定都不授予统计执行权限。整体正式批准与独立开始仍分开，每步执行前核对原批准；变更数据、合同、计划或执行源码后旧批准不会因重新打包而复活。历史只读核对与新的执行授权是不同边界。

## 产品能力限制

- 本地单用户；不具备生产级公网多人认证或租户隔离。
- React仅单表双组二元的受限确定性路径；模型辅助候选、专业工具等仍通过Streamlit。
- 六项已实现确定性规则；其余八项未实现，不生成总体研究可信度分数。
- 随机化声明必须有来源，程序不因分组或均衡推断随机分配，也不证明全部识别假设。
- 无通用多表、自主任意研究、多智能体、持续后台主动诊断或跨任务语义记忆。
- 没有真人独立使用的正式验收数据，固定浏览器脚本不是访谈或真人效率测试。
- 部分旧手册保留历史Streamlit说明，0.21默认启动和React使用以新版安装说明与教程为准。
