# 版本历史

### 2026-11-03 · 0.16.0 第二轮精修

首页主案例改为营销邮件两周访问率，保留葡萄酒入门和合成政策教学。审核区分配置检查和研究声明，结果页和 HTML 报告展示两组比例及绝对差。以指定原始包复验 42,613 人的两组比较，全量本地回归 633 项通过。[操作与验收](current/PHASE2_ACCEPTANCE.md) · [实机截图和流程](../README.md)。

### 2026-11-03 · 0.16.0 公开预览界面更新

首页增加研究问题输入与公开评分分布。导入页支持字段预览；研究工作台分栏展示讨论与计划，人工审核视图并列展示方案与执行条件。研究记录可定位已保存的报告及证据。两个变量的相关图采用成对有效样本和相关系数。README 和图文教程已更新为本次公开样本的实机截图。[审计、验证与剩余限制](current/DESIGN_REVIEW.md)。
