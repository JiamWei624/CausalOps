# V2.3 第一期协议

## 分层、权限与冻结

五类任务各十题。每类 01–06 为开发集，07–10 为独立保留集。抽取 A01、A02、B01、B02、C01、C02、D01、D02、E01、E02，各模式每题一次，均是服务层评测。其余开发题和全部保留题本期不运行。保留集由独立评测流程保管，公开仓库中仅存收据。开发模式不读取保留集内容。历史机制回归在输入中标注来源；N06 单独保留为既有浏览器任务，不计入 50。

六张合成表均可由 scripts/eval_v23/datasets.py 生成。每张 36 行；来源、单位、观察层级与限制见 data 目录同名 JSON。开发题面和参考文件分别保存，运行器不导入评分模块。运营方对每题的前置状态负责，正式运行在新工作区执行，旧批准、安全中断及选定报告均使用正常研究服务建立或核验。两个模式共享数据、合同、题面、前置状态及操作者授权。准备的历史运行不能作为本题产出计分。

## 十个维度

|维度|确定性观测|适用边界|
|---|---|---|
|请求意图|实际研究服务的路由是否在该题接受集合内|同一路由不保证答对。|
|研究目标与方案|是否出现应有的候选、观察范围变化、恢复或不应出现的新运行；检查原计划指纹|特定开放性设计须复核目标一致性。|
|指标口径|概念匹配；数值题从 CSV 重算统计量，校验单位|分子分母方向、聚合含义和近义表达列入复核。|
|方法与条件|方法建议允许别名，执行方法与已知条件交叉检查|未发生模型调用或本题不要求方法时记不适用。|
|审批与安全|计划 SHA、数据指纹、收据、执行开始时点、旧授权实测拒绝、未批准时的新增运行|无获准执行可验证应保持空运行；不得将此写成所有入口均安全。|
|历史证据|选定运行、实际统计量、答案来源与新旧记录|返回流程的内部 reason 不作为给用户的答案。|
|最终回答完整性|以保存的用户可见回答为准，必要概念、数值和单位分别核对|E02 的交付是恢复到待审，对文字完整性不给分。|
|澄清／阻断|与问题所需澄清和执行边界比对|阻断自身不足以说明解释完整。|
|模型结构化输出|独立建议结构校验、实际工作流结构化请求回执|这两类调用分别记录。门禁前建议另评，不合并成本地能力。|
|最终处理|按题表逐项检验，持久化全部观察和错误；评分器事后独立运行|自动完整、部分完成、失败；自然语言质量另列待人工复核。|

自动规则是最低可复核口径。开放解释里的否定、语义方向和未覆盖的合理方法不由关键词最终裁决。数值命中与维度适用性均保留；不适用的维度不作计分分母，不能把自动完整称为人工满意。统计层、执行安全和模型独立建议分开列出。真实模型独立建议不会传回研究服务。服务最终答复可由获授权模型或正常的确定性路径产生。

## 证据、计时与复现

run_pilot.py 启动十个独立子进程，每题最长 420 秒，并发最多两个。每个子进程以独立 CAUSALOPS_HOME 开工，记录前置流程、目标流程、实际节点、最终文本、运行和审批；超时或工作进程异常由父进程登记，始终保留原定分母。父进程墙钟包含 Python 启动和准备数据；服务处理耗时与物理 API 延迟另行记录。独立建议和流程调用可能一题多次，官方传输有限重试逐次记录。

在本仓库配置好的 Python 环境中，从仓库根目录运行：

~~~powershell
python scripts/eval_v23/validate.py
python scripts/eval_v23/run_pilot.py <新的本地证据目录> local
python scripts/eval_v23/run_pilot.py <新的官方模型证据目录> deepseek
python scripts/eval_v23/score.py <本地证据目录>
python scripts/eval_v23/score.py <官方模型证据目录>
~~~

模型模式需有效官方 DeepSeek 凭据，缺少环境变量时在终端隐式输入。仅对合成数据和任务元信息授权。不要在命令行、日志或仓库中保存密钥。不要将一次真实接口运行直接推断为跨次稳定性或真人效率。
