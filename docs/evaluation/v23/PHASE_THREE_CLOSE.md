## 实际调用关系

只读咨询：Streamlit/服务输入 → ResearchService.begin（保留原请求、分离登记背景）→ decide_route → LangGraph 方法检索 → method_context/unit_guidance 或模型 MethodExplanation → design_checked → 保存答案。只读路径不创建新 Plan，也不执行统计。

已有结果：绑定运行 → ToolGateway.answer → AssistantWorkspace.ask → source_dictionary 与已有事实目录 → saved_answer。均值回答的解释与单位转换保留原始事实值、运行编号和窗口；转化值由 Decimal 固定比例产生，不改写运行证据。模型路径的 GroundedReply 继续受原数字引用校验约束，并补充源运行设计声明核对。

明确新计算：仍由原 Plan、版本校验、人工批准、ToolGateway.execute 和统计内核执行。本轮没有新增执行权限。

## 规则边界

- 单位表只支持明确的固定比例；复合单位必须完整匹配，不把 kg/m3 当成 kg，不把百分点当作比例。
- 质量与体积需要密度；电量与排放需要排放因子及边界；减排还需要被替代活动基线。公式不是已计算的本数据结果。
- 随机分配仅引用人工登记合同的明确声明，不代表系统验证了试验实际执行。两组存在、组织层级分配不构成随机证据。
- 文本语义守卫是有限规则，不能保证覆盖任意语言的条件、否定或隐含因果陈述。
- 本地模式未实现面向所有开放式问题的完整推理，方法卡返回可能仍不充分。
- 已登记样本口径不等于所有记录相互独立；均值解释不得虚构实体数或自动删除重复测量。
