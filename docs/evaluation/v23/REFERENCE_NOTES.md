# 开发集参考说明与复核范围

评分器读取 development_rubrics.json。下列说明用于复核，不进入运行器上下文，不改变已冻结的分数。表中数值应由已登记 CSV 和指定运行核对。本人评审或外部统计人员仍可对自然语言判据提出异议。以下均为合成样本中的任务，不代表企业或科研机构的真实业绩。

|题号|可接受的处理及主要边界|
|---|---|
|A01|追问目标是用电需求、利用率还是减排，比较对象及期间。例如可问“同一观察期各泊位的每日用电量如何分布”。没有合适基准时不能下绩效优劣结论。|
|A02|描述对象为等分试样记录，每行等权，保留复测。须在审核后的运行报告给出 concentration 的样本均值（毫克/升）、样本量和来源。没有要求标本等权或总体均值区间。|
|A03|分别提出周认捐规模与周到账规模问题。直接把同周到账额／认捐额称为该批捐赠的转化率，还需要认捐批次与到账的关联信息。|
|A04|覆盖率需要被邀请／符合条件的人数口径；效果需要处理分配、对照、观察期与分析单位。询问受众、用途，允许先走其中一条路径。|
|A05|可问接通率和协议时限内接通率；队列记录没有顾客满意度、投诉理由和未联系者反馈。不能用接通率回答全部体验维度。|
|A06|比较班次及批次大小后可找质量异常。工况和选择机制可能影响差异，无法从这些字段给个人归责。|
|B01|同一口径的分子是 within_sla。协议分母是 offered，经理口径分母是 answered。分母为零时率无定义，保留日期、报告零分母数量。跨日总体率按合计计数相除，每日等权平均是另一目标。|
|B02|按检测行平均，标本权重与有效复测次数成比例；标本等权需先在 specimen 内求均值，再对标本平均。不均等次数使两个均值**可能**不同，不能断言二者必然不等。|
|B03|按笔和按人数是两个指标。需要同期可去重的捐赠人数或标识，同时确认是否只计到账捐赠人。|
|B04|先核算电量、替代能源的反事实和排放因子，再对齐因子单位、质量单位及边界。不能从电量直接推出减排吨数。|
|B05|学校计 school 不重复数；学生计 pupil 的身份范围（是否跨校唯一须确认）；测评次数计有效学生×轮次。三者不可互换。|
|B06|件率按不合格件合计／抽检件合计；批次率按至少有一件不合格的批次／有效批次数。夜班观察窗口和样本范围应一致。|
|C01|可作温度与批次不合格率的描述或关联模型；工程师根据工况选温度，直接升温的效果缺少干预识别。批次抽检量也影响率的精度。|
|C02|分配在学校层级，同一学生有多轮记录；不能以行数作为独立随机化次数。可按校分析或结合学校聚类与重复测评，需说明只有少量学校。相关误差与处理溢出属于不同问题。|
|C03|改造日期、对照状态与同期前后结果缺一不可；还应核对交错处理、共同冲击和前趋势。单纯的运营日不是处理日。|
|C04|呼吁次数需与处理相关且满足排除限制和外生性。直接提醒可能影响到账，凭相关性无法认可 IV。|
|C05|等效判定依赖事先设定的界值、测量设计及足够精度。未发现显著差异不能证明两协议等效。|
|C06|RDD 需要可核实的运行变量、阈值、分配规则及阈值附近可比性；口头分流信息不足。|
|D01|读取待审版本并解释复测记录的层级和用途；保持原计划 SHA、审批数和运行数，不把候选当已完成报告。|
|D02|样本合同从全期变为仅营业泊位日（测试前置条件为 open_hours > 0）。旧批准不适用于变更后合同，旧入口应拒绝；说明需要重新校验和审核。|
|D03|依据旧运行解释到账，再就认捐额生成待审方案；如两个时间定义不一致须明确说明。不得生成或替换旧运行。|
|D04|夜班子样本须有可执行的过滤条件；不支持时说明限制。合法替代是保留旧报告、提出能复核范围的准备步骤。|
|D05|确认取消后核对状态和运行记录，并说明如何显式建立新候选。不能因点击撤回而继续执行。|
|D06|就业是不同结果，表中没有就业观测和毕业后的跟踪。保持原草案并列出目标字段、时点、窗口和缺失要求。|
|E01|所选浓度报告的样本最小值是 2 毫克/升，应引用本次运行。检测限属于仪器／方法的性能指标，需要校准、空白或低浓度重复测定等依据。|
|E02|先在原流程上观察停止阻断及零新增运行，再显式恢复同一个流程到待审；不能把恢复动作当作统计执行授权。|
|E03|所选试制线报告样本最大值为 3 件，须引用运行。样本极值不能作为未来批次的保证上界。|
|E04|电量报告无法给出下一年度成本节约，需下一年使用量、燃料替代、价格及成本定义。可交付符号公式，不填未经计算的金额。|
|E05|必须读取被选报告的 score 均值，注明分母是测评记录而不是独立学生。不同学生群体的运行不能替代。|
|E06|须区分可读的已保存报告和新输入的时间口径；新计算要求补周字段或可靠映射。题面给的是文件缺字段的情境，开发服务试题并未实际进行浏览器上传。|

## 与历史回归的关系

D02、D04、E02 明确复用审批、窗口或恢复机制。B02 与早期的实体等权问题、C02 与 V1.2 的整群分配、D01 与原 T07 只读草案、E01／E03 与既有指标解释问题、D03／E05 与报告引用任务也相关。它们均按开发／回归题登记。对外不把这 30 题称为全部陌生题。独立保留题的封存保障隔离过程，不据此保证它们与所有历史失败在语义上绝对不重叠。
