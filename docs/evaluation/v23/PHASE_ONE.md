## 数据、验证与隔离

五类各 6 道开发题、4 道独立保留题。开发题使用六张 36 行合成表，覆盖港口岸电、科研复测、筹款、学校整群分配、客服服务级别及生产抽检，全部可从 datasets.py 重建。初始历史报告使用合法审核和实际统计运行生成。具有审批失效、历史引用或恢复操作的题目不是只向模型发送文字问题。题面里只有场景、来源、自然语言请求和起点；评分器不被运行器导入。角色设计及 N06 浏览器历史回归另见[后续浏览器任务单](BROWSER_PLAN.md)。

保留集由独立评测流程在 Git 工作树外建立并保管；各类 07–10，共 20 题。其作者另建合成数据、隐藏参考、可实例化的历史工件及复核脚本，报告已从空目录重建并比对清单。保管清单覆盖 90 个文件，清单 SHA-256 为 2975706a3b34998c5052773517f2e494b9389c615cf377b165ab82bb104f59ad。主开发流程仅读取公开收据，核对类别、编号、哈希，不读取隐藏输入或答案。文件隔离依赖流程纪律，尚未部署操作系统级独立账号权限。[公开收据](holdout-receipt.json)

十题运行器、题面和评分器在本地提交 5988bff 冻结后开展第一次试跑。已用 validate.py 核对 30 道题的 ID、类别、规则、数据文件、36 行实际值和数据合同；复算本批两个数值参考，lab 浓度样本最小值为 2 毫克/升，按试样行等权的均值为 2.902777… 毫克/升。Git 默认忽略 CSV；交付中显式收录仅这六张经过生成器校验的合成表。公开收据之外的封存材料继续由独立流程保管。

|题目与正确行为|本地（秒）|模型辅助（秒；物理请求）|实际回答及复核|

## 真实接口、耗时与计费

使用 api.deepseek.com、deepseek-flash、Responses API。10 次独立建议和 8 次工作流请求共 18 次物理请求，均收到 HTTP 200；17 次结构有效，1 次结构错误如实保留。物理请求延迟合计 96.50 秒。本地每题墙钟中位 7.42 秒，十题合计 76.62 秒；模型模式每题中位 18.21 秒，合计 185.57 秒。两路并发，墙钟合计不是整批历时。不是人类用时。

官方回执计输入 28,469 tokens，其中缓存命中 6,528，输出 6,260。按每百万 token 公开费率，同批用量在空闲价为 ¥0.04711，高峰价为 ¥0.09422。记录时刻为北京时间 2026-11-05 11:36–11:38，按工作日高峰规则估计约 ¥0.09422；未读取账单，不能写为实际扣款。[DeepSeek 官方价目](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)

## 下一阶段决定

**可以进入受控的 V2.3 第二阶段，先校准评分与任务起点。当前证据不足以开放保留集或启动 50 题全量运行。**

1. **先复核计分。** A01 明确要求举例，规则只有概念词组，可能给出假完整；B02 需要检查“不一定”和“一定”的区别；C02 要允许概念相同的表述。泛化澄清可能进入“部分完成”。模型填写潜在新增字段（例如 D02 中派生的营业标志名）会触发字段集合严格检查，不能简单解释为伪造现有列。冻结原分，盲审意见另记。
2. **补齐测量。** 本批唯一需要从新任务生成统计的 A02 在两种模式都没有进入有效计算。E01、D02 验证了真实前置运行和旧审批；E02 验证服务层恢复操作。下一次应增加一个能实际形成新获准运行的试点，并另测用户界面的恢复意图。保留集尚未用于诊断。
3. **再考虑业务修复。** 优先复现描述均值被误送比率澄清、只读候选被误送历史结果查询、已引用数值后遗漏概念解释三类问题；目前能确认错误发生在哪条路线，尚未通过本期实验归因到唯一起因。不以本轮任务通过率作为修改业务逻辑的唯一目标。

本地证据根由操作者指定。两组共 20 份观测以只读方式重新评分，与已保存逐题判定 20/20 一致。两模式各有 scores.json 和每题 observation.json、operator/flow 观测、工作区及 status.json；真实模式还保留 requests.jsonl、responses.jsonl、physical_attempts.jsonl。metrics.json 按可核查回执汇总，full.log 为工程测试结果。完整工程测试 777 项通过、0 项跳过，耗时 348.30 秒，其中含 3 项本期评测器测试。源码学习、冻结范围、风险与 Beta 更新建议见 [V2.2 冻结报告](V22_FREEZE.md)。
