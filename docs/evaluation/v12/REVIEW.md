# 首批挑战失败复核
1. **先处理不适用的政策日期。** C04 本地三次都在批准后生成描述统计，未生成促销因果估计，但偏离了应澄清的任务；冻结规则将这种非预期运行记为严重失败。模型模式三次均澄清，且未执行。它们使用 opening_day 说明差异，参考词表未完整识别，正式成绩仍按冻结判据保留。建议结构化记录时间角色冲突，区分无关运行和错误因果估计。

2. **再处理咨询、计算和跨期追问。** C02/C03 的本地通用澄清没有回答加权分母、整群分配等具体问题。C13 的本地回复继续读取旧结果。应对照已选报告的指标、分析单位与时间窗口，标出缺失的顾客追踪资料。C01/C08 的模型路线在独立重复之间切换；保存缺哪个目标或指标的明确理由。

3. **校准评分器后另开盲测集。** 方法建议的严格自动判据同时检查动作、方法字符串和字段。C09 的 pearson_correlation 与 spearman_correlation 是合理方法名，却与冻结别名字典不匹配。C10 修改计划时留空方法也可能合理。保留原分和模型原话，安排双人盲审；不要把严格命中率当作临床或学术专家认可率。

4. **保留故障和校验失败。** C11/C12/C13 各一次在独立建议阶段遇到 ConnectError，未获得计量回执，未进入完整任务。这些计入端到端分母，不能归咎于统计内核。按 request ID 追踪有回执请求，对断线、不合法结构、语义不符分别登记，再测试可恢复性。
