# Eval V2.2 第一期 · 浏览器任务与测量协议

对象为公开 Beta 5f350ab 的 Windows 本地单用户工作台。固定脚本检查界面是否能完成指定流程以及脚本所需的操作。自由探索另开目录、另算分母，本期未运行。八题是设计全集，本轮仅运行 N02、N04、N08，各一次。无真人试用。试题给操作者时只提供下表“题面”和起始页面、允许附件；判据、程序、库文件、服务器日志及其他任务的结果仅控制器可读。

## 八题共同采用的计分口径
- 独立工作区、浏览器上下文。准备测试数据、启动进程、到达规定起点都不计入操作成本。固定路线可通过界面准备起点。记录模式、应用提交、浏览器版本、起止 URL、首末截图和可见文本。
- 起点可操作并保存初始截图后开始单调时钟；达到题目全部终点判据或遇到超时/错误即停，不把最终截图和关闭服务计入。单个控件默认上限 25 秒，统计出口最多等 75 秒。基础设施未达到起点则单列，无任务用时。超时不从尝试分母中删除。
- 一次点击、选择、填写、提交、选择一个文件或显式刷新各计一个发起操作。成功派发给浏览器才计入已派发数；不推定每次操作都推动任务。自动重绘、等待和断言不计。不是鼠标移动或键盘击键总数。产品自动跳转不算用户导航。预置动作应与正式动作分开。
- 一次用户请求已发送才计一轮对话。固定脚本不调用帮助，主动求助为 0；自由探索中由操作者主动打开帮助或向界面请求流程指引才计一次，读已有提示不计。操作员改输入、指路或替代点击每次记一项外部介入，独立完成要求介入为零。固定脚本调试必须另起尝试，不能覆写失败。
- 完成率 = 满足本题所有条件的次数 / 已安排尝试数，同时报告基础设施失败、页面错误及断言误判。恢复率 = 从实际注入或自然发生的故障恢复并达到本题终点的次数 / 遭遇该故障的尝试数。只对 N08 预定注入；其他题无故障时不填 100%。恢复时间从首次显示拒绝，到同一任务刷新恢复。部分成功单列，不计全成功。
- N03、N05–N07 完整实施时，结束后由独立控制器交叉核对审批、运行版本、数值和历史记录；这些后台事实不提供给操作者。对模拟探索只提供当前页面和题面，采取正确停止判据；不得以出现任意数字作为完成。
- 复用 V2.0 的 server、playwright_runtime、BrowserRun.capture 和页面错误/请求失败事件。新增动作尝试、单调耗时、派发成功、故障观察点与阶段状态。每次输出独立目录，保留失败快照。产品内部图节点事件与用户点击属于两套记录，不作等价计数。

## 运行
在安装 Beta 工程依赖、Python Playwright 与 Chromium 的环境，从仓库根目录运行。git 在 PATH 中；CAUSALOPS_HILLSTROM_ARCHIVE 指向公开营销实验官方原始压缩包；已有兼容浏览器可指定 CAUSALOPS_BROWSER_EXECUTABLE。无需 API。执行 `python scripts/eval_v22/pilot.py --out <全新短路径>`。输出包含研究工作区、浏览器事件、统计、截图和文本，仅用于本地验收。不要将工作区提交 Git。
