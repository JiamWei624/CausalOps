## 从九次原始尝试定位问题

- **模型格式与接口。** 第三期有三次额外字段、两次缺少必需字段、一次非法 JSON 和一次响应未完成。51 次请求均收到 HTTP 200。六次格式异常和一次响应未完成导致七次任务中断。第三期未保存被拒的完整原始文本，分类依据是当时的异常、请求回执及操作记录。第四期保存每次实际请求的遥测和可取得的安全模型输出。
- **控件与动作。** 第三期 N06-2 向发送按钮填写文本，使用未定义动作，两次选择不可用控件，并有一次 Playwright 点击等待超时。这些失败要与模型服务的 HTTP 状态分开。
- **导航和停止。** 第三期 N05-1 看到了“购买率”与题面“访问率”不符，仍宣布完成。N05-2 到达了正确报告，此后打开帮助，最终没有交付答案。N06 和 N08 有尝试停在候选阶段或任务创建后，尚未达到各自终点。第三期没有证据将七次中断归因为产品统计故障或外部断网。

## 模拟器改动

scripts/eval_v22/browser_actions.py 定义动作枚举、四个必要字段、控件类型、文件范围和参数检查。每个浏览器步骤最多两次模型请求。只向模型反馈结构或动作约束；拒绝结果、修复原因、请求编号和用量保留在对应 turn.requests。传输错误不自动重试。模型重新生成只产生一个决策，校验通过后才派发浏览器操作。

scripts/eval_v22/explore.py 在派发前重新观察当前页面，检查控件身份、位置和禁用状态。提交文件、发送消息及识别为创建、批准或执行的动作登记已尝试的操作，阻止不确定结果被自动重放。批准仍要经过真实页面和研究服务。标签驱动的保护范围存在局限，基础描述报告快捷按钮的语义见下文。它与正式批准按钮属于两条不同路径。

## 界面改动与核查

1. **研究记录。** workbench.py 使用每份已完成运行绑定的数据字典生成任务和运行选项。history_report.py 显示指标、窗口、已登记比较组与完成状态，缺少分组标签时注明“未登记组间比较”。保留第三期将来源、运行和正文同时渲染的机制。最终专项交替切换六次，19 个不同采样状态中，编号与正文错配 0 次、无来源标签的旧正文 0 次。窄下拉列表仍可能截断长名称。
2. **方案审核。** graph_app.py 在审核区显示前序和候选指标、版本、禁用原因及下一步操作。界面初版误将上份描述统计的两列字段都列为前序目标；保留该批的 5/9。最终代码直接读取前序方案绑定合同和当前方案绑定口径。固定 N06 页面核对值分别为 orders 和 visitors。未自动勾选，审批和执行函数沿用原实现。
3. **导入恢复。** assistant_app.py 针对表头、编码、分隔符等校验错误给出具体提示，文件被拒时不再同时显示等待上传的提示。修正文件通过校验后再启用创建按钮。新任务页显示任务编号和可进行的下一步。

## 固定、补充与工程回归

最终八个固定任务各运行一次，全部通过，共 44 个有效操作。N01～N08 的用时依次为 0.53、3.96、2.11、7.97、15.98、31.64、30.40、5.71 秒。N05 核对任务、窗口、访问率和来源。N06、N07 分别有两个独立批准和运行，验证指标或窗口修改、新报告刷新及旧报告重开。N04 核对下载文件和页面。受影响模块 21 项通过，模拟器专项 13 项通过，最终工程回归 770 项通过，耗时 413.37 秒，0 项跳过。

保留了两项基础设施异常。界面初版固定 N01 的一次断言在控件渲染完毕之前执行；修正等待后仍断言相同控件、数量与禁用状态。两项独立的补充固定导航探针覆盖无对照组的历史研究、编码错误后通过文件设置恢复。历史研究通过；编码探针的原定位两次等待超时，随后通过可见下拉框键盘选择 gb18030，核对实际选中值、成功解析和创建按钮启用，2/2 通过。补充探针不计入八题成绩。它们是固定路线，不能证明自由操作者能发现这些入口。

本轮独立证据根目录为 LOCAL_ARCHIVE

- actor-tests.log、gate-focus.log、final-full.log 保存模拟器、未经批准执行及工程回归的实际日志。

复跑沿用 THIRD_PHASE.md 的环境与公开数据。对新的空目录分别使用 explore.py、grade_explore.py 或 compare_groups.py；history_transition.py、pilot.py、fixed_remaining.py、close_fixed.py 执行固定核验。全量命令为 python -m pytest -o addopts= -q -ra --basetemp <独立测试目录>。公开数据只用于本轮评测。模型成本没有账单实测，自动化样本不提供真人使用率或实际节省时间的依据。

**收尾判断。** 固定流程、审批保护、运行证据、动作失败和可恢复路径均有实测记录。可以进入 V2.2 收尾整理。对外可陈述“已建立真实浏览器对照，验证了报告选择、方案审核和上传恢复”；不能陈述“优化提高了整体任务完成率”。影响最大且值得保留为未决项的是 N06 三次均未独立完成，以及预览指标与基础报告目标之间的差异。
