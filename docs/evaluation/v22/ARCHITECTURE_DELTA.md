# V2.2 架构变更摘要

本页用于后续技术手册维护。V2.2 的工作集中在 Streamlit 页面、研究服务入口的使用方式和独立浏览器评测。核心变化是明确每个页面状态由谁维护，以及某次点击可以产生什么记录。

|---|---|---|

|ui/onboarding.py · render_first_look、preview_actions|前者返回本次分布图所选字段；后者并列展示预览字段、正式指标和版本，根据两者是否一致提供对应操作。|预览改变局部图表；计划、批准和运行均不因预览而创建。刷新后的预览可重新取默认值，正式指标按持久化方案恢复。|

## 从预览到正式报告

门店 V1 报告绑定 orders。选择 visitors 后，工作台能同时展示预览字段 visitors、正式指标 orders 和方案 V1。只有用户点击生成待审方案，界面才调用研究服务的计划入口。V2 有自己的方案指纹和目标字段，服务检查数据、确认项和审批，再执行统计。V2 的访客均值来自新运行。回到 V1 时，订单均值仍来自原运行。前端不会用预览字段覆盖已批准方案的 DataContract。

以上路径通过共同时间窗口的描述统计任务验证。多步复杂计划仍需按各步的合同和证据分别复核。一个方案有多项已完成输出时，快捷入口的运行上下文不提供逐输出选择；需要消歧的场景应核对选定报告，不宜仅凭快捷入口的摘要决定口径。
