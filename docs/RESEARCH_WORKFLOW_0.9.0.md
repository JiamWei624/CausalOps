# CausalOps 0.9.0：方法研究、数据字典与后台运行

本版完成四项工程交付，独立用户验收尚未开展。它是本机单用户研究工作台，不是能够从任意表格自动证明因果关系的系统。

## 完整操作顺序

1. 启动工作台，选择“分析工作台”，导入CSV或Parquet。读取上限仍为50MB、10万行、200列，解码后256MB；原始文件不改写。
2. 展开“数据字典与研究口径”。先登记一行代表什么、结果、处理、实体、时间、自变量或协变量、指标单位与观察窗口。只有IV、RD或交错DID才需要对应进阶字段。
3. 在“字段说明”登记测量时点；在“研究声明”保存有依据的事实。不要为了启用按钮而全部勾选。无法确认时保持未知。保存需要本人明确确认。
4. 输入研究问题。系统形成注册方法候选，检索规则卡；缺少专门方法规则时补检，最多三轮；没有新依据或达到上限即停止。没有可靠来源时不补造引用。
5. 页面展示候选方法、实际检索轮数、规则覆盖与待确认条件。方法卡齐全不表示数据适用。文献案例不作为本表已经满足识别条件的证据。
6. 核对待审计划。数据字典中同一方法的声明会预填，仍需本次接受计划并批准执行。批准绑定数据、字典、计划、知识库和代码指纹。修改字典后须重新制定计划。
7. 计算在本地后台进行。页面可查看真实节点进度，并可提出停止请求；正在运行的底层统计函数会先完成当前安全边界，不强制杀死进程。已完成结果保留。
8. 停止或异常后，明确点击“检查批准并继续流程”。系统核对原批准和指纹，并利用原统计任务的检查点保留已完成步骤，不把恢复理解成重新估计全部结果。
9. 报告和问答绑定具体运行。继续提问实际含义、结论边界或来源，不会自动重跑。原始数据行、模型密钥不写入图状态或后台任务记录。

## 已实现架构

Streamlit → ResearchService → LangGraph主图 → 方法研究子图 → 待审计划 → 审核中断 → TaskRuntime及三类原统计执行器 → ToolResult → 运行级证据问答。

方法子图为真实编译子图：scope → retrieve → assess → retrieve或finish。LangChain Core的BaseRetriever适配已有字符TF-IDF检索；不是全文向量库，也没有联网自主抓取文献。当前仍为20张卡、27条来源；六部分为“适用问题、数据要求、识别条件、诊断方法、失败情形、结果解释”。本轮优化检索流程与使用条件，并未把未阅读的文献标成已阅读全文。

DataContract保存本地人工声明。SQLite表workflow_data_contracts按会话与版本持久化；新请求冻结contract_ref。字段不存在、角色冲突、未来/处理后变量、版本冲突和人工事实不一致会阻止不适当复用。自由口径备注不自动发送模型。

BackgroundJobs采用Python ThreadPoolExecutor单工作线程，SQLite持久化排队、运行、停止请求、等待审核、失败和中断状态。最多四项活跃/排队任务；页面使用Streamlit fragment定期读取真实进度。进程身份使用PID与创建时间匹配，不能抢占仍存活的原工作进程。模型认证仅存内存，恢复模型任务须重新提供并授权原配置。

## 自动化验收的定义

- 真实数据验收使用三份新UCI数据及既有Hillstrom邮件实验。完整行数由本地实际文件统计，非引用网页的汇总数。
- 新数据分别为红葡萄酒1599行、购物会话12330行、银行营销45211行。银行表派生subscribed，购物Revenue布尔转整数；不删除数据行。
- 八个端到端场景包括：描述统计、OLS、Logit、随机实验及三项应阻断的设计风险。数字对照使用独立statsmodels调用或原始两组均值差。真实观察数据没有已知因果真值，不将拟合一致当作因果正确。
- 17项方法逐一检查专门规则卡覆盖；这些是明确方法名的工程检索验收，不是开放任务准确率。有限补检、无新增依据和三轮预算另外以固定夹具测试。
- 真实浏览器测试上传、审批前阻断、后台完成、报告下载、字典保存与复用、方法咨询和页面重载。它属于自动化验收，不替代陌生用户测试。
- 真实API仅使用固定合成任务，记录模型使用量和校验修复。失败记录保留，不能用本地摘要冒充模型成功。

## 本轮修复

1. 注册方法内部名称与AIPW/IPW的词形重叠不再造成静默换方法；无模型且专门设计口径不足时说明需要补充。
2. 依据明确结构化路由限定候选范围；模型若额外加入未请求分析，进入一次有限修复，而不是直接保存。
3. Logit不再用原始单位系数绝对值判断疑似分离。改用单标准差对比的保守数值保护，保留分离警告、收敛、矩阵秩与有限推断检查；该保护不是分离统计检验。无法安全计算的exp系数保留空值，不截断伪造有限值。
4. 修复后台状态自动刷新的竞态。停止状态更新使用比较条件，避免覆盖已经完成的任务。

## 仍然保留的边界

不会从表格本身确认随机化、工具变量外生性、排除限制、平行趋势或无干扰。模型没有批准、接受人工事实或执行的权限。四项队列是本地线程队列，不是分布式任务平台；本版不提供多用户权限隔离、跨主机调度、任意代码执行或流式HTTP服务。取消不是强制中断统计计算。独立用户完成率、返工率和节省时间尚无实测，不写入简历作为提升百分比。
