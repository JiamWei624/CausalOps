## 本次修复与约束

目标指标、展示名称和单位保存在用户确认的口径版本中。分析运行绑定当时的数据、口径、计划与批准；之后换目标不能改写旧结论。宽表中位于默认字段上限之外的已登记目标仍须包含在描述计划中。目标未计算时明确告知，不能用别的字段代替。

首次实测发现选择框的未知项为空白，已修正。真实模型曾把同一字段同时放入数值和分类角色；现在候选生成阶段即检查，并把被拒绝候选和具体原因送入最多一次有限修复。仍不合法则阻断，不静默改变计划或继承批准。

目标结论只引用已保存统计。观察范围不当作置信区间，描述均值不当作干预提升。目标主图、问答证据选择和 HTML 报告使用同一冻结口径。用户明确询问其他字段时，证据可优先该字段；普通“同意”不能触发执行。

## 验收范围的边界

自动脚本按真实控件输入，没有预置研究事实，未授权模型执行或批准。真实模型测试由测试程序明确批准公开样本的描述计划，该批准不是模型发出的。没有发送原始行、用户/帖子 ID 或论文全文。

这不是独立人类可用性研究。尚未验证任意数据表、任意研究、Linux/macOS、公网多用户或所有服务商真实账户。真正“首次使用者无需开发者指导”的人类验收仍需后续开展。当前结果只能称自动化首次使用链路验收通过。
