## 浏览器实际完成的链路

首页品牌与正式功能标题 → 填写非真实测试凭据 → 配置区自动收起，且不误报连接成功 → 清除测试凭据后导入公开葡萄酒数据 → 自动数据概览与初步建议 → 生成可引用建议 → 输入“采用第一项建议” → 待审方案与前序对话关联 → 人工批准 → 结论及保存的实际统计量优先显示 → 展开图表并下载 → 追问结果 → 刷新后恢复记录。

浏览器同时确认图表详情初始收起。描述统计结论引用保存运行中的均值、中位数与有效数，按固定字段顺序展示前三项，不按显著性筛选；未新增估计，也不推断干预收益。

## 连续对话边界测试

- 建议序号必须实际存在，且属于当前任务、数据和口径版本。
- 同一上传文件创建的另一个任务也不能引用该对话为上文。
- 口径已变更时，旧建议序号不能直接沿用，需重新确认建议。
- 只有明确的建议选择表达才解析为相应问题；不把“同意”等普通消息当作批准。
- 历史候选仅是上下文，不继承研究事实或执行权限；跨任务引用被拒绝。
- 上文问题与历史候选配置可用于模型理解，不发送内部流程 ID，不把历史回答当作新的数值证据。
- 结果引用当前选定运行，图表和报告仍保留来源字典及运行证据。
