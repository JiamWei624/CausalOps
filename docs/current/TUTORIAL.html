完整示例教程 · 0.15.0

首次体验不需要知道葡萄酒指标，不需要密钥，也不需要编写代码。公开数据说明、每行含义、质量评分和单位由经过内容校验的示例说明提供。

真实操作录屏 · 安装说明 · 五类真实数据体验 · 验收与边界

1. 载入示例

启动后核对页面版本为 CausalOps 0.15.0。首页点击 载入葡萄酒示例。这是 UCI Wine Quality 的红酒子集，1,599 行、12 列：每行是一条红葡萄酒样本的理化检测与感官评分记录。quality 为感官质量评分，官方定义范围 0–10 分，属于有序评分。

来源：UCI 官方说明、DOI，数据许可 CC BY 4.0 独立于代码 MIT 许可。红酒原始文件 SHA-256：4a402cf041b025d4566d954c3b9ba8635a3a8a01e039005d97d6a710278cf05e。UCI 同时提供白酒文件，页面总览不应混用为本例行数。

2. 查看已准备的说明

示例页直接说明数据是什么、每行代表什么、quality 是什么，以及建议问题“质量评分如何分布，数据是否存在缺失或重复记录？”。字段说明包含中英文名称。没有成本、售价、品牌、处理时点或随机分配，不能据此计算利润或证明调整配方有效。

点击 使用示例说明并生成分析计划。这次点击确认采用可见的行含义、目标 quality、名称“质量评分”、单位“分”和描述性问题。只创建待审计划，不自动批准计算，不授予外部模型发送许可，也不确认独立性或因果假设。

如需改动，展开 逐项核对或修改示例设置。内容已预填，无需自己查找术语；自己的研究设置不会被示例快捷入口静默覆盖。系统按数据内容识别示例，不只看文件名；把其他文件改名为 winequality-red.csv 不会套用葡萄酒含义。

3. 审核与执行

查看待审计划的字段和输出。勾选“我已核对上述计划和本步骤必要事实，同意按当前数据与计划版本进行本地计算”，再点 接受计划并批准本次执行。聊天中只说“同意”不能授权执行。

如果还不理解，可以先问方法适用条件，再通过 返回待审计划 继续核对。修改数据、目标、日期或计划后需要按新版本审核；日期或目标改变时，新口径不会沿用旧研究声明。

4. 理解质量评分与图表

先显示目标结论和主图。当前红酒样本 quality 有效记录 1,599 个，均值约 5.636 分，中位数 6 分，实际出现的评分为 3–8 分。评分频数图按实际整数取值展示，不再以连续小数区间切割。

这些是本样本的分布，不是某项措施“提高了多少分”。观察范围不是置信区间，均值不代表每条记录。完全重复记录 240 条不自动等于错误，程序未删除；应结合采样过程判断。

5. 继续一个新问题

点击 查看限制与下一步，或问“我还可以研究什么？”。后者进入针对已登记目标的问题推荐，不再机械重复上一份均值结果。

选择“质量评分与其他指标的关联”下的 制定分析方案。系统会保存所选建议的序号、问题与两个字段，生成新的待审计划。先前结果会标明为旧结果，新计划未审核前不会计算。审核执行后，主图优先显示相关矩阵，结论说明目标变量对及实际系数。

相关只表示共同变化，不能证明增加某理化指标会改变评分。没有预设随机分配、处理前后或成本时，不能从这张表推算生产策略收益。

6. 报告与恢复

点击直接可见的 导出本次分析报告。HTML 先给本次问题的结论，再附图表、口径、数据质量和证据。刷新后任务、计划与结果仍可恢复；旧结果继续绑定原口径，不随新输入改写。JSON 证据位于详情中，私人报告不要随意公开。

7. 上传自己的表

首页 导入分析数据 → 选 CSV / Parquet → 创建任务。CSV 默认保守识别逗号、分号、制表符；存在多个可能解释时要求手动确认，不猜测。可在“文件编码与分隔符设置”中指定编码及分隔符。原始记录不去重、不填零、不修改。

自己的表仍按三步确认行含义、目标字段及单位、分析意图。第二步发现日期候选时，可以选择 日期字段（可选，用于时间图）；不确定就跳过。year 等纯数值不是完整日期，不能直接当日期解析；季度数据需按实际来源构造并明确日期含义。

缺失统计指实际空值；unknown、-1 等业务代码不一定是空值，需按领域说明核实。字段名和数值编码不自动证明业务含义、独立性、随机化或处理前测量。

8. 模型连接与使用边界

首页可选连接模型，服务商、API 模型 ID 与密钥均需对应；每个任务单独控制摘要外发。密钥只存内存，不发送原始行、用户/帖子 ID 值或论文全文。视频使用本地模式，字幕为步骤说明，不是模拟任务进度。

当前支持本机单用户；上传限 50MB、10万行、200列，解码后限256MB。不能把脚本验收称为独立陌生用户成功率或工时节省。

安装、启动与故障恢复 · 0.15.0

本文面向第一次运行 CausalOps 的使用者。先完成本地示例，再选择是否接入模型。仓库公开只代表源码可获取，不代表把本机工作区公开或提供在线多人服务。

1. 需要准备什么

• 已验证平台：Windows 64 位、Python 3.11。先执行 python --version 与 python -c "import platform; print(platform.architecture()[0])"。其他 Python 主版本或操作系统未在本次发行复现中验证。

• 磁盘：建议在数据盘预留 6 GB，并使用较短的工作区路径（例如 E:/cops-work），避免 Windows 深层文件名限制；完整依赖约数 GB，CSV/Parquet 与结果另计。内置示例仅约 84 KB。实际新环境占用以验收记录为准。

• 浏览器：可访问本机 127.0.0.1 的现代浏览器。无需安装 MySQL、Java、Hive、Docker、Power BI 或下载本地大模型。

• 模型 API 是可选项；本地示例和基础统计不需要账号、密钥或外网。

2. 在线安装（从源码目录执行）

在 GitHub 的 Code 菜单下载 ZIP 并解压，或使用 Git 克隆仓库。把项目放在数据盘。以下 E 盘只是可替换的路径示例，不要求与作者机器目录一致。

New-Item -ItemType Directory -Force -Path "E:/causalops-temp", "E:/causalops-cache/pip", "E:/causalops-cache/matplotlib"
$env:TEMP = "E:/causalops-temp"
$env:TMP = "E:/causalops-temp"
$env:PIP_CACHE_DIR = "E:/causalops-cache/pip"
$env:MPLCONFIGDIR = "E:/causalops-cache/matplotlib"
$env:PYTHONDONTWRITEBYTECODE = "1"
python -m venv "E:/causalops-env"
& "E:/causalops-env/Scripts/python.exe" -m pip install -r requirements-runtime-win-py311.txt
& "E:/causalops-env/Scripts/python.exe" -m pip install --no-deps .
& "E:/causalops-env/Scripts/python.exe" -m pip check

不使用系统 Python 的 site-packages，不需要管理员方式运行。不确定解释器位置时，用 where.exe python 检查；带引号的完整解释器路径前使用 PowerShell 调用符 &。

3. 离线安装

完整离线包包含 wheelhouse、依赖哈希锁、应用 wheel 哈希、许可证资料与安装器。仅源码 ZIP 没有依赖包，不能冒充离线安装包。解压后在该目录执行：

python install_offline.py --destination "E:/causalops-env-new"

离线包已固定换行规则，UCI 原始 CSV 按二进制原样保存，避免 Windows Git 自动换行改变校验值。

目标环境必须不存在；安装器不会删除旧环境。安装器核对 Python 3.11、逐项依赖 SHA-256 和应用 wheel SHA-256，执行 pip check，并用隔离模式确认导入的是新环境中的应用。数据与旧工作区不会被迁移或删除。

4. 统一启动

& "E:/causalops-env/Scripts/python.exe" -m causalops.launch --workspace "E:/causalops-work" --port 8513

保留启动进程。使用终端本次显示的完整地址，形如 http://127.0.0.1:8513/?route=home&release=0.15.0&build=...；省略 --port 时同样使用 8513。首页与其他主页面顶部显示实际版本及构建号。源码快捷启动脚本和安装版均进入同一个工作台。若使用源码目录的双击脚本，请先为该次启动指定已经安装依赖的解释器，或把虚拟环境放在源码目录 .venv 中。脚本不再回退到作者机器的其他目录或旧版作品集。

$env:CAUSALOPS_PYTHON = "E:/causalops-env/Scripts/python.exe"
& ".\启动作品集.cmd" --workspace "E:/causalops-work" --port 8513

工作区保存上传文件、SQLite 研究记录、检查点、图表、报告与临时文件。应用自动把自身缓存和临时目录放在工作区内。不要把工作区加入 Git。浏览器会话中的 API 密钥不会写入工作区；服务停止后可能需重新输入。

5. 更新与旧页面

先等待后台任务完成或在界面请求停止，然后停止旧服务、更新应用。保留原工作区后重新启动。只对本项目登记的进程允许：

& "E:/causalops-env/Scripts/python.exe" -m causalops.launch --workspace "E:/causalops-work" --port 8513 --restart

启动器核对进程创建时间、命令与服务归属；后台任务未结束时拒绝重启。其他程序占用端口时不关闭它，改用其他端口。更新代码后，旧批准不会自动迁移到新计算；程序会核对绑定版本。不要删除数据库解决界面问题。

旧书签未必包含构建号，旧标签页也可能仍显示先前渲染内容；先用本次输出的完整地址重新打开，再核对顶部实际版本。本教程不把任何旧页面问题未经检查就归因于浏览器缓存。

7. 部署边界

代码开放与 Web 服务开放是两件事。当前服务只监听本机，面向单用户；没有公网鉴权、多租户隔离、恶意文件沙箱或分布式任务队列。不要直接改监听为公网地址。独立用户验收仍待进行，自动浏览器复现不是人类用户效率对照实验。
