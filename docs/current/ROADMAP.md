# 当前范围与后续工作

## 当前优先级

0.16.0 第二轮已验证营销实验从原始文件、人工审核到报告与结果追问的路径。下一步安排独立使用者分别完成实验、解释百分点、识别超出窗口的请求，记录完成率、误读与返工。[当前验收证据](PHASE2_ACCEPTANCE.md)

## 前期版本记录

0.15 增加有来源的示例预填、五类真实数据体验修复、问题推荐到计划的连续传递，以及任务对应的可视化。0.14 已补充三步首次引导、运行时目标驱动的结论、首要图表与报告；首页示例/导入优先，方法咨询后可返回待审计划。此前版本已统一正式交互语言，补充导入后的自动概览、有限连续对话关联与结论优先展示。公开版安装、公共示例、逐步教程和真实录屏已补齐；下一步优先做独立新用户验收，记录完成率、错误与返工；不要在没有实测前声称节省时间。新增方法应由真实任务需求驱动。公网多租户、跨机器自主协作和任意表自主因果识别未实现。


## 已实现

- 数据导入、版本化人工字典、安全元数据路由、方法研究子图、就绪检查。
- 版本批准、原17项统计方法、本地后台队列、协作停止和恢复。
- 主要结果选择、量化解释、来源字典绑定、证据问答与报告。
- 多服务预设、只读MCP、本地A2A规则审阅。

## 尚未证明或实现

- 独立用户的完成率、返工率与工时节省：本轮按用户要求暂缓，不写提效百分比。
- 任意表格自动发现可信因果关系：无法仅靠表格确认随机化、无混杂、外生性、无干扰等事实。
- 通用预测训练与样本外评估流水线：当前关联模型不能冒充此能力。
- 多租户鉴权、公网部署、分布式任务调度、HTTP/SSE服务：不在本机验证版能力中。
- 自主跨模型A2A研究、外部MCP宿主闭环、联网无限扩展文献：未作为本轮已完成事项。
- 全文向量文献库：当前为有来源的规则/案例卡，不把未阅读全文标为已审阅。

## 下一次扩展的前提

先根据固定真实任务的失败及独立用户验收提出具体需求，再选择方法、协议或界面扩展。每项扩展须说明数据条件、来源、失败边界与验收方式，不以框架数量代替实际效果。
