# 当前操作说明 · 0.10.0

核对日期：2026-11-01。本文描述实际实现，旧版本操作见[历史索引](../HISTORY.md)。

## 导入与提出问题

在“分析工作台”上传CSV或Parquet，创建任务。数据概况包括行列数、类型、缺失、非有限值、疑似标识与完全重复行；不会自动删除记录或把缺失补零。

已知信息先写入“数据字典与研究口径”：一行代表什么、结果和分组、实体、日期、指标单位及窗口。用于条件关联的自变量和处理前协变量分开；未知随机化、测量时序或独立性保持未确认。

可以问“随机邮件是否增加访问”“控制这些因素后评分相差多少”“这个变量在预测时是否已经可得”。不必预先指定方法。信息不足时，系统应提出具体问题；它不能根据两组标签确认随机化。

## 查看候选与缺项

页面顶部显示当前任务、状态和下一步。候选会列出主要分析、字段和来源；若缺少对照编码、结果字段等配置，批准按钮不可用，并显示缺项。

不要为了继续操作而勾选未知事实。应先补充字典，保存新版本，再点击“按最新口径重新制定计划”。旧候选、旧批准不适用于新口径。

## 审核与执行

方法卡完整只说明找到规则，不能证明本表满足识别条件。人工声明可从原字典预填，但本次仍须审阅计划并明确批准。模型没有批准权限。

后台计算使用本地官方包。进度来自实际节点；停止为协作式停止，正在运行的底层计算不会被强制杀死。中断后可核对并恢复已保存的流程；已完成步骤不会因结果追问重复计算。

## 阅读与追问结果

系统优先展示本轮主要分析，而非最后执行的附属描述统计。结论按四部分组织：参考水平、差异幅度与区间、实际含义及限制、行动建议。

回归系数不等于干预收益；Logit的OR及其区间不是概率比、百分点或边际效应；没有成本不报告利润或ROI。统计显著不等于值得上线，区间包含零也不自动等于没有影响。

可以继续问样本、区间、变量单位、诊断和为什么不能推广。问答绑定选定运行及其来源字典，不会使用后来修改的字典重写旧结果。

报告含图表、四部分结论与来源证据。模型服务失败或回答不通过引用检查时，页面明确显示本地摘要，不能把它当作模型成功。

## 模型与隐私

配置服务商、实际API模型ID和协议，输入密钥，然后单独授权当前任务的发送范围。切换服务配置后需重新授权；服务失败不偷偷换另一家。密钥不写盘，重启后重新输入。

真实API验收只证明特定服务、任务和本次配置的表现。当前仍是本机单用户版本，不能直接作为公网多租户服务。
