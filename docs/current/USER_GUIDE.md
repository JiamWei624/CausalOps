# 操作说明 · 0.16.0

[完整公共示例教程](PUBLIC_TUTORIAL.md) · [安装与故障排查](INSTALLATION.md)

## 模型连接与数据导入

首页使用 CausalOps 品牌标题，提供模型连接和数据导入两个主要入口。连接配置为可选项：未配置时支持本地统计；配置模型后，可获取模型辅助建议与解释。

连接配置始终为可选折叠项，已配置时显示服务与模型摘要。页面区分“已配置，尚未验证连接”与“连接已验证”，不会仅凭填写密钥声称认证成功。展开连接配置可以修改服务、模型或密钥，也可以运行固定测试。密钥只保存于会话内存；重连或停止服务后可能需重新输入。

首次使用可点击首页“载入葡萄酒示例”，不依赖外部下载或作者目录。也可点击“导入分析数据”，选择 CSV 或 Parquet，填写可选任务名称，再登记文件。模型连接不授予数据发送权限：每个任务仍需分别允许发送字段摘要、研究问题与运行汇总；不发送原始行、用户或帖子 ID 值及完整论文。

## 数据概览与初步建议

导入后自动展示记录数、字段数、主要字段、缺失单元格和完全重复记录。原始记录保持不变，不自动去重、填零或剔除异常值。

系统同时展示依据字段结构生成的初步建议，不必先选择统计方法。此时没有调用模型、没有估计研究结果。连接模型并授权当前任务后，可进一步生成模型辅助建议。模型输出不通过字段检查时，明确采用本地建议，不能标作模型成功。

首次导入后，按三个问题逐步确认：一行代表什么、关注哪个指标及单位、希望回答哪类问题。未知的信息可以留空；确认分布目标会建立待审计划，不直接计算。“其他分析起点”内仍可使用“生成基础报告”描述统计快捷入口；它仍保存版本化方案、批准记录与运行证据，不能运行回归或因果研究。

## 分析对话与方案确认

可输入分析目标、方案调整要求或结果解读问题。选中建议后，会建立相应待审方案；也可明确输入“采用第一项建议”。序号只引用当前对话中实际展示的建议，不凭空推断，且需属于当前任务、数据和口径版本。

后续请求保存原始提问、解析后的问题与上文引用。模型可读取有限的上文问题和历史候选配置以理解请求，不能据此修改人工事实、接受方案或执行统计。普通“同意”消息不代替审批按钮。

三步引导可保存分析单位、目标指标和单位，完成后可点“调整分析目标”重新设置。未知内容保留为空。完整数据字典、测量时序与研究声明放在高级设置；模型不得凭列名确认随机化、独立性或处理前测量。

待审方案保持展开，显示方法、字段、步骤和必要确认项。配置完整后，核对实际条件并批准本次执行。可先咨询方法，再通过“返回待审计划”继续审核；修改方案时展示与前序方案的真实字段差异。已完成方案收起保留；字典、数据或代码变化后，旧批准不自动适用于新分析。

## 分析结果与后续讨论

先展示分析结论，再按需展开图表、诊断和报告。描述性报告直接引用保存运行中的均值、中位数、有效观测数及数据质量记录；优先解释运行时已确认的目标指标，并将对应图表置前；没有指定目标时才按稳定字段顺序展示，不按显著性挑选。单位未明确时保留原始字段名，不猜测量纲。

回归与研究结果继续区分参考水平、幅度与区间、实际含义和建议。描述、相关或条件回归不自动构成干预收益；OR 不是概率比或百分点；未登记成本时不报告 ROI。

结果下方直接提供“导出本次分析报告”，报告先呈现目标结论再给完整表格。结果追问仅使用选定运行的证据，不重新估计。前序对话可展开查阅，最近关联链展示最多六轮；完整保存记录仍可通过历史选择恢复。跨任务引用会被拒绝。方案、方法依据、流程记录和精确证据在详情中保留。

## 运行与适用边界

后台为本机单用户工作线程，支持明确停止与版本核对后恢复。上传限制 50MB、10 万行、200 列，解码后限制 256MB。尚无公网多用户权限系统与通用预测训练流水线。

自动化验证不替代独立用户可用性研究，也不能证明任意表可以自主完成因果研究。未知业务事实与识别条件仍需由研究者确认。


## 0.15 的示例与外来表区别

内置示例可用官方说明预填，点击后仅登记明确的元数据并生成待审计划。外来表不因文件名相似而套用示例；需逐步确认行含义和目标，可选日期用于时间图。未知编码与测量尺度需要来源说明。完整操作见[更新后的教程](PUBLIC_TUTORIAL.md)。


## 错误后的直接操作

首页模型连接测试失败会撤销旧的成功标记，并提供“使用本地模式继续”。后续请求不调用模型，已输入配置和任务许可保留；恢复模型辅助需明确点击。已启动请求需要单独停止，原模型流程不能被静默转换为本地继续执行。

当流程失败、被阻断或需要补充说明时，显示已保存统计运行数，并提供“补充字段与研究口径”和“按当前口径重新制定待审计划”。前者打开真实口径编辑区，后者只生成新候选，不批准、不执行、不继承旧批准。
