# 首次使用与操作说明 · 0.11.0

## 1. 先在首页连接模型

启动后首页首先展示模型配置。选择实际服务商，填写 API 模型 ID 和密钥。“模型名称”指服务 API 可调用的 ID，不是聊天应用中的显示名。服务基础地址和协议在高级连接设置中；不要把具体 `/responses` 或 `/chat/completions` 路径填进基础地址。

点击“测试模型连接”只发送固定测试，不发送数据表。密钥仅保留于本次浏览器连接的服务端内存，切换页面不应丢失；关闭服务或重新建立会话后需要重填。不同服务/地址的密钥分开保留，不会把旧密钥自动发给新地址。

没有密钥时也可以继续。基础统计和本地方法规则仍可用，页面会说明未调用模型。

## 2. 上传，不必先选统计方法

点击“开始分析我的数据”，选择 CSV 或 Parquet，填写可选任务名称，再点击“创建任务并检查数据”。该按钮只登记文件与检查结构，不等于已经完成研究。

页面以文件或你填写的名称识别任务，不把内部编号当作任务标题。行列数、缺失、疑似标识字段来自本地检查；系统不根据列名猜测一行是什么，也不会自动删除重复记录、填零或删除异常值。

模型发送许可按数据任务和服务配置分别确认。允许的范围是过滤标识后的字段元数据、汇总、研究问题、有限上下文及运行数字事实；不发送原始行、用户或帖子 ID 值、完整论文。

## 3. 选择一个明确的起点

**生成基础报告**：点击即明确授权本地描述统计，自动建立版本化计划、保留批准记录，再运行缺失、分布、频数与图表。只允许描述统计，不自动运行回归或因果方法。相同数据、口径和代码的已完成基础报告会复用；排队中的同一报告不重复提交。

**推荐分析方向**：根据安全字段摘要生成最多三个问题卡片，包括涉及字段、待补信息和限制。没有模型时使用本地规则，并明确标注。推荐不等于结果，卡片不能声称已经算出提升幅度。点击“沿这个方向继续”才创建后续待审计划。

**直接提问**：在分析对话中用业务语言描述目标。手动选择请求类型只在高级设置中需要，不必知道路由名。例：“分析这张表的分布”“我可以根据它研究什么”“解释本次结果的实际含义”。还没有运行时，系统会说明先生成哪种结果，不再暴露内部布尔字段。

## 4. 只补充自己知道的事实

“补充两项信息”可填写每行代表什么、关心哪个结果和单位。所有输入按用户声明保存，不自动确认独立性、时间先后或随机分组。完整数据字典、字段时序、研究声明与版本记录在高级设置中。

需要关联或因果分析时，系统会列出必要角色和事实。不要为使按钮可点而勾选未知条件；先核对业务资料，再保存字典版本并重新制定计划。旧批准不继承到新数据、口径或代码。

## 5. 查看计划后计算

普通分析计划列出方法、字段、步骤和缺项。配置完整后，核对本步骤相关事实并点击接受与批准。模型只能建议，不能执行这个审批动作。基础报告的按钮授权是一个严格限制到描述统计的快捷入口，不是给模型的通用批准权。

后台进度来自实际节点；停止在安全边界生效，不强杀底层统计计算。中断后保留已完成步骤，可核对版本后继续。

## 6. 读结论，继续问

结果显示参考水平、估计幅度与区间、实际含义和后续建议。描述报告回答“样本有什么特点”，回归回答“给定条件下有何关联”；只有有依据的研究设计与诊断才支持受限的因果解释。

继续问样本、单位、诊断与局限时，回答读取选定运行，不重新计算。查看多条历史结果时注意选择范围。报告和 JSON 保留原运行证据；模型失败或回答不通过校验会明确退回本地摘要。

## 常见情况

- **首页配置好，任务仍显示本地模式**：检查是否勾选本任务的数据发送许可，以及是否更换过服务/模型/协议。
- **提问只给问题建议，没有系数**：推荐阶段没有执行统计；选择问题或生成基础报告。
- **不知道什么方法合适**：直接描述目标，必要时补充每行含义和结果指标，不必猜选 A/B。
- **结果显著**：仍须考虑单位、幅度、区间、成本及研究设计，不能直接当成策略有效。
- **页面更新后显示旧运行**：旧结果保留原代码和口径，重新计算必须基于新的明确授权。

独立新用户可用性研究尚未完成；本手册配合自动浏览器验收，不代表外部用户已经成功上手。
