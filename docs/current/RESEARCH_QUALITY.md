# 研究质量与用户体验升级 · 0.16.0

本轮目标：使用户明确看到**系统理解了什么、依据是什么、计算了什么、结论适用于谁、还缺少什么**。版本仍为本地单用户预览版。独立用户验收暂缓；仓库保持私有。

## A 研究定义与数据语义

导入数据后继续沿用三步引导。分析过程中打开“研究摘要与待确认事项”，可查看研究问题、分析单位、目标指标、比较对象、估计目标、观察期间、数据来源与外推范围。没有说明的内容保留未知，不由模型补成事实。

点击“补充研究范围与字段口径”，进入“研究范围”页，登记适用对象、纳入排除说明、比较对象、估计目标、观察期间、决策用途、数据来源和额外限制。字段页可以登记测量时点、来源和派生逻辑。**登记纳入排除说明不会自动筛选数据**，实际筛选仍须进入待审计算计划。研究范围等新增自由文本目前保存在本地，不自动加入模型外发上下文；既有字段摘要发送仍服从任务许可。

质量检查分为四层：

| 层次 | 实际检查 | 用户应如何处理 |
|---|---|---|
| 结构 | 空值、完全重复行、常量 | 核对数据字典，不自动删除重复或填补 |
| 统计 | 无穷值、特殊编码候选、3倍四分位距极值、零值集中、稀疏类别 | 判断数值是否有效；提示不等于异常已经确认 |
| 关系 | 实体—日期键重复、重复实体、日期解析 | 确认每行粒度；不能将重复测量直接当独立样本 |
| 研究 | 结果兼作控制、处理后/未来协变量、来源与对象缺失 | 修正角色、时点与研究范围，未知保持待核对 |

检查只读取数据和聚合计数，不修改原表。界面优先显示最多三条待确认事项，其余在完整清单内展开。质量快照随本轮数据和口径版本保存。清单中的“阻断风险”是需要修正的局部问题；实际是否允许某种计算仍由该方法的原有校验决定，不能因为无关字段有问题就阻止所有描述统计。

## B 统计与状态可靠性

17个注册方法均提供可展示的方法合同：估计目标、实际适用样本、必要诊断、解释限制、原始来源链接与知识库指纹。合同是说明，不替代计算设置或识别论证。

本轮针对源码修正：

- PSM：匹配后平衡使用与匹配前一致的标准化分母；常量却不同均值不再被记为零差异。保留匹配比例、未匹配处理单位、1:1不放回设置和估计范围。零配对方差不再输出零P值与零宽区间。条件配对标准误没有计入全部匹配不确定性，不应作为充分验证的确认性推断。
- DoubleML PLR：固定实际分折并保存分折指纹；重叠检查直接使用本次模型的折外倾向预测，不再另拟合一组模型。转换整数前检查处理变量二元性，拒绝非有限数值和不受支持的重复实体；当前不实现聚类交叉拟合。
- A/B 与 CUPED 共用验证：拒绝非有限输入及被误当独立单位的重复标识；退化均值差推断不以零标准误冒充确定性。
- 变量角色：结果字段不能同时进入同一模型的预测或控制变量。
- 版本：研究质量快照、结果解释和导出报告绑定当时的数据与口径；修改当前范围不会重写历史报告。原审批、失败恢复和过期计划保护继续回归测试。

这些改动不是所有统计方法在所有数据条件下的认证。IV外生性/排除限制、RDD连续性/无操纵、DID平行趋势以及观察性无遗漏混杂仍需要研究依据。

## C 研究协作、来源与报告

流程结束或需要补充时，“可继续开展的研究”提供最多三条选项，按已登记的目标、变量及质量风险选择：先补口径、制定分布/关联计划、咨询识别条件或明确研究问题。按钮只创建待审方案或咨询，不自动批准计算。

结果页新增“研究范围、计算依据与待解决问题”。摘要首先说明适用对象；详情列出实际估计目标、样本口径、诊断问题和后续建议。对未通过的诊断，建议先核对设计与口径，而不是反复试方法追求显著。PSM单独提醒匹配后样本和推断限制；DID提醒前趋势与处理时点。

导出的HTML报告追加以下内容：研究问题、适用对象、纳入排除说明、比较对象、观察期间、来源与决策用途；实际样本数或逐字段有效样本说明；保存的计算设置；未解决问题和下一步；方法来源、知识库指纹、运行ID及口径版本。全部基于保存运行读取，不在导出时重新估计。

RAG保持小型可核对的资料库。本轮为PSM和DoubleML补充官方方法依据与限制；资料记录包含来源、版本与阅读范围。它不是完整论文数据库，也没有新增全文授权。缺少依据时仍应说明未知，不生成虚构引用。

## D 复现与展示

使用[安装说明](INSTALLATION.md)安装并启动，先选择公共葡萄酒示例。用户路径：载入示例 → 查看目标与待审计划 → 检查研究摘要 → 按需补范围 → 人工批准 → 阅读目标结论与图表 → 查看适用范围 → 导出报告 → 继续追问或建立下一轮计划。

首次试用无需填写全部研究字段。描述样本分布可以保留比较组为空；若希望解释干预收益，必须补足比较对象、时序、分配机制和识别依据。未知信息不应为了让按钮可点而随意勾选。

## 边界与后续

已实现的是本地审计、方法合同、版本绑定报告和受控建议。尚未完成独立用户研究、复杂样本设计的普遍统计认证、大文件延迟查询、多表自动关联、完整因果DAG及全部文献全文。自动浏览器测试不能替代真实首次使用者；本轮未新增真实模型API评测，不能据此宣称AI回答准确率提升或工时节省百分比。

原数据、密钥、个人论文与运行数据库不随源码或安装包发布。分析数值只在本地统计工具产生；模型、文档检索与普通聊天均不能代替人工批准。
