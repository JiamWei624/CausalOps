# 系统架构与执行边界（0.7.0）

[当前架构核查与目标图](ARCHITECTURE_REVIEW_0.7.0.md) · [LangGraph迁移方案（尚未实施）](LANGGRAPH_MIGRATION_PLAN.md)

![当前真实架构](assets/architecture-current.svg)

CausalOps 是本机单用户的模块化研究工作台。统计估计在本地运行；可选的结构化模型客户端提出待审计划、解释既有证据和决定有限的只读观察步骤。它不从表格自动确认随机化、变量时序或因果识别，也不让模型批准或执行新分析。

## 主流程

`CSV/Parquet → GeneralWorkspace登记与双指纹 → AssistantWorkspace任务 → MethodLibrary检索 → Plan候选 → 人工接受/登记研究事实 → TaskRuntime检查点 → AnalysisTools适配器 → 原统计引擎 → ToolResult契约 → 运行选择/结果问答/报告`

界面为Streamlit；任务、版本、运行引用、执行尝试和对话保存在SQLite。原始数据副本为本地Parquet。无需LangChain/LangGraph；主流程使用明确的HTTP协议适配器（旧专业表单保留SDK）和本项目的受限状态机。

## 三类执行器与统一合同

`assistant/contracts.py` 的 REGISTRY 枚举17个可执行方法：探索5个、研究8个、进阶4个。模型配置模式、执行分派和方法范围从该注册表读取。原有因果识别注册表仍负责CausalSpec内部路由，不与通用任务注册表混淆。

- ExplorationDesign：描述、相关、OLS、Logit、Poisson。
- GeneralDesign → CausalSpec：A/B、CUPED、关联回归、PSM、IPW、DoubleML、AIPW、共同处理时点DID。
- AdvancedDesign：2SLS、清晰/模糊RD、交错DID。保持各自已验证的样本、设计与诊断边界。

ToolResult统一保存运行编号、数据集标识、数据指纹、结果指纹、方法、解释等级及计划版本。原始统计结果不强行重写为一种格式；适配层加载原证据并核对归属与哈希。修改表、配置或运行引用不会静默成为另一项研究。

## 运行级问答与研究上下文

当前讨论与展示的运行由assistant_focus持久保存。问答默认只加载这条运行；比较须明确选择同一任务的二至三条运行。不同任务即使上传同一表也不能互用运行证据。旧运行的问题使用旧运行的来源计划，不使用最新候选冒充其设计。

研究上下文以数据版本、选定运行、来源计划、人工登记的类型化标记、未解决项、已拒绝方法、近期同范围问题和已校验引用组成，并保存指纹快照。人工登记不是模型推断或经验验证。上下文不包含原始行、ID值或设计依据自由文本。

回答保留运行范围、知识库指纹、方法来源快照与精确事实；数值由本地事实占位符插入。跨运行讨论不附加到单运行报告，以免混淆估计对象。单运行报告使用回答当时的来源快照，不被后来修改的知识卡覆盖。

## 持久执行与恢复

assistant_checkpoints保存执行令牌、所属进程创建标识、心跳、输入摘要、准备后的研究/运行引用和取消标记；assistant_attempts保留每次尝试的开始、结束与状态。SQLite事务取得执行所有权，过期令牌不能覆盖结果。重试输入摘要包括计划、数据、步骤、人工事实和执行源码指纹。

- 原进程仍存在或身份不明时，不窃取执行权；心跳超时本身不是可以重跑的证明。
- 原进程已退出时，先按准备检查点查找已完成运行。探索与进阶使用预留运行编号；研究使用该步骤专属研究与草案引用。
- 已有结果先验证并复用；没有完成记录才进入可继续状态。相同输入最多三次尝试；改设定需新候选或重新登记。
- 取消为协作式：待执行步骤立即取消，正在执行的统计函数先结束并保存结果，再停止后续步骤。未实现对任意上游函数的强制中断。

这是本地统计任务的检查点与结果调和，不是跨外部系统的严格exactly-once事务。尚未注册的输出文件可能需要重算；同一进程内失去响应的上游线程不能仅凭超时安全接管。

## 有界观察与重规划

EvidenceLoop只能inspect_run、search_methods、ask_fact、propose_revision、finish。最多三项动作、共享三次应用级模型调用（包括修复）；超过一分钟不开始下一次调用。单个已发出的SDK请求受客户端超时控制，预算不等于能硬中断网络或上游计算。

inspect_run仅读取已保存的诊断与解释等级；search_methods只检索方法库。缺事实时停止询问；用户明确允许后，才可生成待审修订。候选仍需另行接受和审核。重复动作、校验失败、服务失败、调用上限均记录停止原因。没有直接执行、接受或批准工具，也没有自动按显著性替换方法的路径。

## 方法RAG

当前20张方法/实证卡、27条来源、120个原创摘要章节。每张卡按适用问题、数据要求、识别条件、诊断方法、失败情形、结果解释组织。实证论文来源严格保留摘要或已核对相关全文页的范围，不标成全部全文已读。

检索使用现有scikit-learn字符TF-IDF和章节分数，不宣称嵌入向量库或全文语义搜索。命中保留章节位置、摘要指纹、来源链接、页码/定位、核对日期、访问范围及知识库版本。摘要为项目原创提炼，不是原文逐字引文。引用仅限本轮实际命中卡片；段落、来源或版本被改动时拒绝。检索不到已核实方法时明确返回不足依据。

固定开发回归集比较原检索和章节检索；不将其称为独立用户评测或通用模型准确率。固定开发集中发现的Welch别名遗漏已补齐；该集参与了改进过程，其命中率变化不能推断为开放问题性能提升。

## 协议、隐私与部署

MCP提供只读方法检索和明确导出的运行数字事实。A2A为本机独立规则审阅服务，非第二个自主研究大模型。二者不改变统计解释能力或授予审批权限。CSV/Parquet仍受50MB、10万行、200列及解码内存限制；无任意Python/SQL执行、无多租户鉴权，不直接部署公网。

模型授权以任务为范围；默认不外发。预览并获授权后，仅发送过滤字段元数据、汇总、研究问题、有限上下文和数字事实。不上传原始行、用户/帖子ID值或完整论文。过滤规则不是匿名化安全证明。

## 0.7.0 模型与协议扩展

ProviderConfig绑定服务/地址/模型/协议/输出格式。StructuredModelClient统一三类HTTP协议并本地校验JSON，授权按完整绑定核对。配置核验不授予外发权限，密钥仅内存。当前通用配置不改写旧专业表单的DeepSeek启动设置。

MCP现有五项只读工具，A2A新增已导出运行事实的一致性检查；版本、工作区指纹与固定本机端点均核对。A2A审阅不持有模型密钥。详见[0.7.0接入与边界](PROVIDERS_PROTOCOLS_0.7.0.md)。
